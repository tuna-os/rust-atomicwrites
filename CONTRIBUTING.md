# Contributing to rust-atomicwrites

Thank you for contributing to `rust-atomicwrites`! This library provides atomic file-write operations on POSIX and Windows systems.

## Maintenance Notice & Fork Status

This repository is maintained within the **TunaOS** ecosystem (`tuna-os/rust-atomicwrites`). Bug fixes and compatibility updates are welcome.

## Local Development & Testing

### Prerequisites

- [Rust toolchain](https://www.rust-lang.org/tools/install) (stable `cargo`, `rustc`)

### Verification

Run the test suite locally before submitting changes:

```bash
cargo test
cargo check
```

## Commit Guidelines & DCO

All commits must include a Developer Certificate of Origin (DCO) sign-off line:

```bash
git commit -s -m "docs: add CONTRIBUTING.md guide"
```
